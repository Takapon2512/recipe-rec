# 画面設計書

家庭用 在庫管理・献立支援システム

設計方針：**Figma連携（パターン1：Figmaが真）／モバイル375pxファースト／レスポンシブで PC対応**

## 1. Figma連携の運用方針

### 1.1 役割分担

| 対象 | 管理場所 |
|------|---------|
| ピクセル単位のレイアウト・スタイル | **Figma**（真の情報源） |
| デザイントークン（色・タイポ・スペーシング） | **Figma Variables** |
| コンポーネントライブラリ | **Figma Components** |
| 画面遷移のクリッカブルプロトタイプ | **Figma Prototype** |
| 画面一覧・機能仕様・API連携・状態管理 | **本Markdown（screens.md）** |
| エッジケース・バリデーション・空状態 | **本Markdown** |

### 1.2 Figmaファイル構成

```
📁 Figma File: 家庭用在庫管理アプリ
├── 📄 Cover                    # ファイルの説明
├── 📄 Design Tokens            # 色・フォント・スペーシング・角丸
├── 📄 Components               # ボタン、入力欄、カード、ヘッダー等
├── 📄 01 Auth                  # 認証系画面
├── 📄 02 Inventory             # 在庫管理画面
├── 📄 03 Recipes               # レシピ画面
├── 📄 04 Calendar              # 献立カレンダー画面
├── 📄 05 Recommendations       # LLMレシピ提案画面
├── 📄 06 Settings              # 設定・プロフィール画面
└── 📄 Prototype                # 画面遷移プロトタイプ
```

### 1.3 Figmaリンクの記法

各画面のリンクは以下の形式で記載する：

```
https://www.figma.com/design/{file_key}/{file_name}?node-id={node_id}
```

`node-id` を含めることで、その画面（フレーム）にピンポイントで遷移できる。

> ※本ドキュメントの Figmaリンクは現時点ではプレースホルダー（`{TBD}`）。Figma作成後にURLを差し替える。

## 2. 共通レイアウト

### 2.1 画面構造（モバイル）

```
┌─────────────────┐
│   ヘッダー       │ 56px ← AppBar（タイトル・戻る・メニュー）
├─────────────────┤
│                  │
│   メインコンテンツ │ 可変 ← スクロール領域
│                  │
├─────────────────┤
│ 🏠 📦 📅 🍳 ⚙️  │ 64px ← BottomNavigation（5タブ）
├─────────────────┤
│  Safe Area      │ env(safe-area-inset-bottom)
└─────────────────┘
```

幅375px、最大幅は640pxまでにしてPCでも違和感ない表示。

#### 2.1.1 共通レイアウトの寸法

| パーツ | 高さ | 用途・備考 |
|-------|------|-----------|
| ヘッダー（標準） | **56px** | 詳細画面・フォーム画面で使用。戻る/閉じる + タイトル + アクション |
| ヘッダー（簡略） | **48px** | メイン画面（一覧系）で使用。タイトルなし、アクションアイコンのみ |
| ヘッダーなし | 0px | ホーム（S-101）。挨拶やアクションをコンテンツ最上部に配置 |
| BottomNavigation | **64px** | アイコン24px + ラベル12pxが収まる高さ。5タブ等幅 |
| Safe Area（下部） | デバイス依存 | iOSのホームバー領域。`env(safe-area-inset-bottom)` で吸収 |
| ボトム固定フッター（フォーム画面用） | **72px** | プライマリボタン48px + 上下余白12px。S-203/S-303等で使用 |
| FAB（Floating Action Button） | 56×56px | BottomNavigationの上、右下16〜24px余白 |

#### 2.1.2 コンテンツ領域の計算

通常画面（BottomNavigationあり）:
```
コンテンツ高さ = 画面高さ - ヘッダー(56) - BottomNav(64) - SafeArea
```

フォーム画面（BottomNavigation非表示、ボトム固定フッターあり）:
```
コンテンツ高さ = 画面高さ - ヘッダー(56) - フッター(72) - SafeArea
```

スクロール領域内では、スクロール開始位置がヘッダー直下(top: 56px)から始まる。固定要素（ヘッダー・BottomNav・ボトムフッター）はスクロールの影響を受けない。

#### 2.1.4 ヘッダーの方針（画面別）

メイン画面ではヘッダーを軽量化または廃止し、縦スペースを最大化する方針。詳細・フォーム画面では戻る導線とコンテキスト明示のため通常ヘッダーを採用。

| 画面 | ヘッダー仕様 | 備考 |
|------|------------|------|
| S-101 ホーム | **ヘッダーなし** | 挨拶（「おはよう、たろうさん」）と設定アイコンをコンテンツ最上部に配置 |
| S-201 在庫一覧 | **簡略ヘッダー 48px** | タイトル省略、検索・ソートアイコンのみ右寄せ |
| S-301 レシピ一覧 | **簡略ヘッダー 48px** | タイトル省略、検索アイコンのみ |
| S-501 カレンダー | **簡略ヘッダー 48px** | 月表示+月切替矢印（タイトル代わり） |
| S-601 設定トップ | **簡略ヘッダー 48px** | タイトル省略 |
| S-202 / S-302 / S-502 等 詳細画面 | **通常ヘッダー 56px** | 戻る + タイトル + アクション |
| S-203 / S-303 / S-503 等 フォーム画面 | **通常ヘッダー 56px** | ×閉じる + タイトル |
| S-205 / S-404 / S-504 等 サブ画面 | **通常ヘッダー 56px** | 戻る + タイトル |
| S-001〜S-007 認証系 | 画面ごとに最適化 | スプラッシュはヘッダーなし、サインアップ/ログインは通常56px |
| S-701〜S-703 エラー画面 | 通常ヘッダー 56px | ホームへ戻るボタン |

##### 簡略ヘッダー(48px)の構成
- 高さ: 48px
- 左: 通常は空(またはロゴ)
- 右: アクションアイコン1〜2個(検索・ソート等、24×24px、タップ領域44×44px)
- 背景: 不透明 or 半透明(コンテンツのスクロールに応じてサーフェス色)

##### 通常ヘッダー(56px)の構成
- 高さ: 56px
- 左: 戻る矢印 or `×`(24×24px、タップ領域44×44px)
- 中央: タイトル(text/h2、`color/text-primary`)
- 右: アクションアイコン0〜2個

#### 2.1.5 BottomNavigationを表示する画面 / しない画面

| 画面群 | BottomNavigation |
|--------|-----------------|
| 認証系（S-001〜S-007） | **非表示** |
| メイン画面（S-101 / S-201 / S-301 / S-501 / S-601） | 表示 |
| 詳細画面（S-202 / S-302 / S-502 など） | 表示 |
| フォーム系（S-203 / S-204 / S-303 / S-503 / S-504） | **非表示**（代わりにボトム固定フッターで保存ボタン等を配置） |
| エラー画面（S-701〜S-703） | 文脈による |

#### 2.1.6 横幅と余白

| 項目 | 値 |
|------|-----|
| 画面幅 | 375px基準、最大640pxまでセンタリング |
| 左右の標準余白 | 16px |
| カード間の縦余白 | 8px〜12px |
| セクション間の縦余白 | 24px |

### 2.3 共通コンポーネント

Figma Components で管理。すべての寸法はモバイル375px基準で定義。

#### 2.3.1 Button

| バリアント | 用途 |
|-----------|------|
| `primary` | 主要アクション（保存、提案を見る、ログイン等） |
| `secondary` | 副次アクション（保存して続けて追加、キャンセル等）線のみ |
| `danger` | 破壊的操作（削除、退会） |
| `ghost` | 強調しないアクション（テキストのみ） |

サイズ:

| サイズ | 高さ | パディング(左右) | フォント | 用途 |
|-------|------|-----------------|--------|------|
| `sm` | 32px | 12px | text/caption (14px) | カード内・密集UIで使用 |
| `md` | 40px | 16px | text/body (16px) | 標準サイズ。フォーム内アクション等 |
| `lg` | 48px | 24px | text/body (16px / 600) | 主要CTA、フォーム送信、ボトム固定フッター |

共通仕様:
- 角丸: `radius/md` (8px)
- アイコン併用時: アイコン20px + テキスト、間隔8px
- タップ領域: 最小44×44px (Apple HIG / Material 推奨)
- 非活性時: 不透明度40%、カーソル不可
- ローディング時: スピナー表示、テキスト非表示、ボタン幅維持

#### 2.3.2 Input

| バリアント | 用途 |
|-----------|------|
| `text` | 1行テキスト（商品名等） |
| `number` | 数値入力（数量等）。モバイルでは数値キーボードを呼び出す |
| `date` | 日付ピッカー連動 |
| `select` | プルダウン or ボトムシート連動 |
| `textarea` | 複数行（メモ等） |

寸法:

| 項目 | 値 |
|------|-----|
| 高さ(text/number/date/select) | **48px** |
| 高さ(textarea) | 最小96px、自動拡張 |
| パディング(左右) | 12px |
| フォント | text/body (16px) ※iOSで16px未満だと自動ズームされるため必須 |
| 角丸 | `radius/md` (8px) |
| 枠線 | 1px `color/border` |

状態:

| 状態 | 表示 |
|------|------|
| `default` | 枠線 `color/border`、背景 `color/surface` |
| `focus` | 枠線 `color/primary` (2px)、シャドウ薄く |
| `error` | 枠線 `color/danger`、下にエラーメッセージ12px |
| `disabled` | 不透明度40%、背景灰、カーソル不可 |

ラベル: 入力欄の上に配置、text/caption (14px)、`color/text-secondary`、入力欄との間隔 4px。

#### 2.3.3 Card

| バリアント | 用途 |
|-----------|------|
| `default` | 静的な情報カード |
| `interactive` | タップ可能なカード(在庫カード等)、軽いアニメーションあり |

寸法:

| 項目 | 値 |
|------|-----|
| パディング(内側) | 16px |
| 角丸 | `radius/lg` (12px) |
| 背景 | `color/surface` (`#FFFFFF`) |
| シャドウ | `0 1px 2px rgba(0,0,0,0.04)`(elevation 1) |
| ボーダー | なし(または 1px `color/border`、デザインで使い分け) |
| 高さ | 内容に応じて可変。在庫カードは80px固定 |

interactive 時:
- タップでわずかに沈む(scale: 0.98)、リップル効果なしでも可
- アクティブ状態の背景色変化(`color/background` に近づける)

#### 2.3.4 Badge

| バリアント | 背景色 | 文字色 |
|-----------|-------|-------|
| `info` | `#DBEAFE`(青薄) | `#1E40AF`(青濃) |
| `success` | `#D1FAE5`(緑薄) | `#065F46`(緑濃) |
| `warning` | `#FEF3C7`(黄薄) | `#92400E`(橙濃) |
| `danger` | `#FEE2E2`(赤薄) | `#991B1B`(赤濃) |

寸法:
- 高さ: 20px
- パディング(左右): 8px
- フォント: text/small (12px / 500)
- 角丸: `radius/sm` (4px)、または完全な楕円(高さ÷2)も可

#### 2.3.5 Modal

| バリアント | 用途 |
|-----------|------|
| `confirm` | 削除確認、退会確認等の意思確認 |
| `form` | 短い入力(例: 名前変更ダイアログ) |

寸法:

| 項目 | 値 |
|------|-----|
| 幅 | 画面幅 - 32px (左右余白16px)、最大400px |
| 中央配置 | 画面の縦中央 |
| パディング | 24px |
| 角丸 | `radius/xl` (16px) |
| 背景 | `color/surface` |
| シャドウ | `0 20px 25px rgba(0,0,0,0.15)`(elevation 4) |
| オーバーレイ | `rgba(0,0,0,0.5)`、タップで閉じる(confirm系は閉じない) |

構成:
- タイトル(h3、18px / 600)、下に余白16px
- 本文(text/body)、下に余白24px
- ボタン2つ横並び(キャンセル/確定)、各幅50%、高さ48px(Button `lg` 相当)

破壊的操作(削除等)では確定ボタンを `danger` バリアントに、左にキャンセル・右に確定の配置。

#### 2.3.6 Toast

| バリアント | アイコン | 背景色 |
|-----------|--------|-------|
| `info` | ℹ️ | `color/text-primary`(濃グレー) + 文字白 |
| `success` | ✓ | 同上 |
| `error` | ⚠️ | `color/danger` + 文字白 |

寸法:

| 項目 | 値 |
|------|-----|
| 幅 | 画面幅 - 32px、最大400px |
| 高さ | 最小48px、内容に応じて可変 |
| 配置 | 画面下部、BottomNavの上64px (BottomNavなしなら下16px) |
| パディング | 12px 16px |
| 角丸 | `radius/md` (8px) |
| フォント | text/body (16px) |
| アクションボタン | 「取り消し」等を右寄せに配置可能、ghost白 |

挙動:
- 表示: スライドイン(下から、200ms ease-out)
- 消滅: 3秒後に自動消滅(エラーは5秒、取り消し付きは5秒)
- 連続発生: 直前のトーストを置き換える(重ねない)

#### 2.3.7 EmptyState

寸法:

| 項目 | 値 |
|------|-----|
| 配置 | 親要素の中央(縦・横とも) |
| イラスト | 120×120px |
| イラスト下の余白 | 16px |
| タイトル | h3 (18px / 600)、`color/text-primary` |
| 説明 | text/body (16px)、`color/text-secondary` |
| CTA(任意) | Button `md`、説明から24px下 |

#### 2.3.8 LoadingSpinner

| バリアント | サイズ | 用途 |
|-----------|------|------|
| `inline` | 16〜20px | ボタン内、テキスト横 |
| `default` | 24px | カード内のローディング |
| `fullscreen` | 32px、画面中央 | 画面全体のローディング |

色: `color/primary`、回転速度 1秒/周。

#### 2.3.9 ErrorBoundary

予期しないエラーをキャッチして表示する画面全体のフォールバック。

構成:
- イラスト(エラーを示すもの)
- タイトル「問題が発生しました」(h2)
- 説明文
- `再読み込み` ボタン(Button `md` primary)
- 連絡先(任意)

EmptyState の構成に近いが、`color/danger` 系のアクセントを軽く入れる。

#### 2.3.10 SegmentControl(参考、S-203 等で使用)

横3〜4分割の択一ボタン群。

| 項目 | 値 |
|------|-----|
| 高さ | 40px |
| 角丸 | `radius/md` (8px)、外側のみ |
| 背景(全体) | `color/background` |
| 選択中 | 背景 `color/surface`、シャドウ薄く |
| 非選択 | 背景なし、文字 `color/text-secondary` |
| フォント | text/body (16px / 500) |

#### 2.3.11 BottomSheet(参考、S-203 カテゴリ選択等で使用)

| 項目 | 値 |
|------|-----|
| 高さ | 内容に応じて、最大画面の80% |
| 角丸 | 上端のみ `radius/xl` (16px)、下端は0 |
| ハンドル | 上部中央に小さなバー(36×4px、灰色) |
| 背景 | `color/surface` |
| オーバーレイ | `rgba(0,0,0,0.5)`、タップで閉じる |
| アニメーション | 下から200ms ease-out |

## 12. 共通仕様

### 12.1 状態の表現

各画面・コンポーネントで考慮する状態：

| 状態 | 表示 |
|------|------|
| `loading` | スケルトン or スピナー |
| `loaded` | 通常表示 |
| `empty` | 空状態（イラスト + CTA） |
| `error` | エラーメッセージ + 再試行ボタン |
| `offline` | オフラインバナー |

### 12.2 トースト通知

| 種別 | 用途 |
|------|------|
| `success` | 「在庫を追加しました」「献立を保存しました」 |
| `error` | 「保存に失敗しました」 |
| `info` | 「コードを再送しました」 |

3秒で自動消滅、上部にスタック表示。

### 12.3 確認モーダル

破壊的操作（削除、退会）は必ず確認モーダルを挟む。確認操作には `削除する` のような明確な動詞を使う。

### 12.4 アクセシビリティ

- すべての画像に `alt` 属性
- フォーム要素に `label` 紐付け
- フォーカスインジケータ可視化
- 配色は WCAG AA（4.5:1）以上
- スクリーンリーダー対応（aria属性）

### 12.5 国際化（将来検討）

`Accept-Language` ヘッダで切り替え可能な多言語対応の素地は残す。当面は日本語のみ。
