## S-203 在庫追加
 
**URL**: `/inventory/new`
**Figma**: [{TBD}]({TBD})
 
### 🎯 目的
- 買い物帰りや冷蔵庫整理時に、最小タップ数で在庫を登録する
- 連続登録（買い物帰りに5つまとめて）にも対応する
- 入力ハードルを下げ、後からでも詳細を補える設計にする
### 📋 構成要素
 
#### ヘッダー（上部固定）
| パーツ | 配置 | 内容 |
|-------|------|------|
| `×` 閉じる | 左 | キャンセル動作 |
| タイトル | 中央 | `在庫を追加` |
| `保存` | 右 | プライマリボタン（必須項目埋まるまで非活性） |
 
#### ヒントバナー（初回のみ）
- 上部に薄い背景色のバナー：「💡 商品名と数量だけ入れればOK」
- `×` で閉じると以降表示されない（localStorageでフラグ管理）
#### フォーム本体（縦スクロール）
 
##### 必須セクション
| フィールド | 入力UI | 仕様 |
|-----------|-------|------|
| 商品名 ※ | テキスト入力 + サジェスト | 1〜100文字、過去履歴から候補表示 |
| 数量 ※ | 数値入力 | > 0、小数2桁まで、デフォルト `1` |
| 単位 ※ | プルダウン | `個` / `g` / `kg` / `ml` / `l` / `本` / `枚`、デフォルト `個` |
 
数量と単位は **同じ行に並べて表示**（数量60% / 単位40%）。
 
##### 任意セクション（折りたたみ可、初期は展開）
| フィールド | 入力UI | 仕様 |
|-----------|-------|------|
| カテゴリ | ボトムシート選択 | タップでボトムシート、未選択時は「未分類」として保存 |
| 保管場所 | セグメントコントロール | 冷蔵 / 冷凍 / 常温（カテゴリ連動の自動推測あり） |
| 期限 | プリセット + カレンダー | プリセット（今日/3日後/1週間後/1ヶ月後）+「その他」でカレンダー |
| 購入日 | カレンダー | デフォルト：今日 |
| メモ | テキストエリア | 最大500文字、3行表示 |
 
#### フッター（画面下部固定）
2ボタン横並び：
- 左：`保存` （プライマリ、塗り）→ 一覧へ戻る
- 右：`保存して続けて追加` （セカンダリ、線）→ フォームクリアして同画面に残る
### 🔄 インタラクション
 
#### 商品名サジェスト
- 1文字以上入力でドロップダウン表示
- 過去30日以内に登録した同名商品（重複除外、最大5件）
- タップで商品名のみ追従、他項目は履歴から自動補完：
  - **カテゴリ**：履歴から最頻値を自動セット
  - **保管場所**：履歴から最頻値を自動セット
  - **数量・期限**：補完しない（毎回違うため）
#### カテゴリ選択（ボトムシート）
- タップでボトムシートが下から出現（高さ画面の60%）
- カテゴリリスト：よく使う順 → 五十音順
- 選択時：シート即閉じ + フォームに反映 + **保管場所を自動推測**
  - 肉・魚 → 冷蔵
  - 冷凍食品・アイス → 冷凍
  - 調味料・米・乾物 → 常温
  - その他 → 既定値なし
- ユーザーが手動で保管場所を変えた場合はそちらを優先
#### 保管場所（セグメントコントロール）
- 横3分割：`冷蔵` / `冷凍` / `常温`
- タップで即選択
- カテゴリ連動の推測値はうっすらハイライト、ユーザータップで確定
#### 期限入力
- プリセットボタン4つを横並び：`今日` / `3日後` / `1週間後` / `1ヶ月後`
- タップで該当日付がフォームに入る、ボタンが選択状態に
- 「その他」ボタンで標準カレンダーピッカー
- 未入力（未選択）も許容
#### 「保存して続けて追加」の挙動
- 保存成功 → 短いトースト「鶏もも肉を追加しました」（2秒）
- フォームの一部をクリア：
  - **クリアする**：商品名、数量、期限
  - **保持する**：カテゴリ、保管場所、購入日、単位（直前の値）
- 商品名フィールドにフォーカスを戻す
- 連続登録で同カテゴリの食材を素早く登録できる
#### キャンセル動作
- ヘッダー左 `×` タップ、またはOSの戻るジェスチャー
- 入力状態を判定：
  - 商品名が未入力 **かつ** 数量がデフォルト `1` のまま → 警告なしで戻る
  - 何か入力済み → 確認ダイアログ表示
    - タイトル：「入力中の内容が破棄されます」
    - 本文：「保存せずに戻りますか？」
    - ボタン：`戻る`（キャンセル）/ `破棄して戻る`（破壊的、赤）
### 📡 データ・API
 
```
GET /api/categories                # カテゴリ一覧（初期表示）
GET /api/inventory?q={商品名}&...  # 商品名サジェスト用（過去履歴）
POST /api/inventory                # 保存
```
 
#### POST リクエストボディ例
```json
{
  "name": "鶏もも肉",
  "quantity": 300,
  "unit": "g",
  "category_id": 2,
  "storage_location": "fridge",
  "expires_at": "2026-05-12",
  "purchased_at": "2026-05-08",
  "memo": null
}
```
 
### 🌀 状態
 
| 状態 | 表示 |
|------|------|
| `default` | 通常フォーム、保存ボタン非活性 |
| `valid` | 必須項目埋まり、保存ボタン活性 |
| `submitting` | 保存ボタンスピナー表示、フォーム入力ロック |
| `success` | トースト表示 → 動線分岐（戻る or 連続入力） |
| `error` | エラーメッセージ表示、再送信可能 |
 
### ⚠️ エッジケース
 
#### 入力エラーの表示
- エラー項目の **直下に赤字メッセージ**（12px / `color/danger`）
- 該当項目の枠線も赤に変わる
- 保存ボタンはエラー解消まで非活性
- **初回フォーカス前はエラー表示しない**（入力前に赤くしない配慮）
- 一度フォーカスを離れた（blur）以降からバリデーション開始
#### バリデーションルール
| 項目 | ルール | エラーメッセージ例 |
|------|--------|------------------|
| 商品名 | 1〜100文字 | 「商品名を入力してください」「100文字以内で入力してください」 |
| 数量 | > 0 の数値 | 「1以上の数値を入力してください」 |
| 単位 | 選択必須 | （プルダウンなので発生しない想定） |
| 期限 | 過去日も許容 | （特になし） |
| メモ | 最大500文字 | 「500文字以内で入力してください」 |
 
#### サジェストAPIの遅延・失敗
- サジェスト取得失敗時：黙ってサジェストなしで継続（フォーム入力を妨げない）
- 1秒以上応答ない場合：サジェストドロップダウンは表示しない
#### 保存API失敗時
- フォーム入力は維持
- 上部に赤いエラーバナー：「保存に失敗しました。もう一度お試しください」
- 保存ボタンを再度活性化
#### 連続入力中の離脱
- 「保存して続けて追加」を押した直後にOS戻る → 警告なしで一覧へ（直前の保存は完了している）
#### オフライン時
- 保存操作：エラートースト「オフラインです。接続後に再度お試しください」
- ローカルキューイングは行わない（実装複雑度を下げる方針）
### 💭 設計判断メモ
 
| 判断 | 理由 |
|------|------|
| 必須項目を3つに絞った | 入力ハードルを下げる。買い物帰りの疲れたタイミングで使われる前提 |
| カテゴリ未選択を許容（未分類扱い） | 「あとで分類すればいい」を可能にする |
| ボトムシートでカテゴリ選択 | モバイルでスクロールしやすく、視認性が高い |
| 保管場所はセグメントコントロール + カテゴリ連動 | 3択は最速UI、自動推測で入力ゼロを目指す |
| 期限プリセットボタン | 「3日後って何月何日？」の計算を不要に |
| 商品名サジェストは名前のみ追従 | 過去の期限が誤って入る事故を防ぐ |
| カテゴリ・保管場所は履歴から自動補完 | 表記揺れ防止と入力速度の両立 |
| 「保存して続けて追加」ボタン | 買い物帰りシーンで連続登録を快適にする |
| 連続登録時、カテゴリと保管場所を保持 | 同カテゴリのまとめ買いに最適化 |
| 入力エラーはインライン表示 | 何が問題か即座に分かる、HTML5標準UXに近い |
| 初回フォーカス前はエラー非表示 | 入力前から赤くしないユーザー配慮 |
| キャンセルは入力状態で分岐 | 安全性と煩わしさのバランス |
| 初回ヒントバナー + コンテキスト誘導 | 押し付けず、必要なときに学べる |
| ローカル下書き保存はやらない | 実装複雑度を抑える、要望が出てから検討 |
